# 3.2.1.1 Use Case Diagram

The use case diagram presents the L.A.R.A. system boundary and the functions available to its Learner, Teacher and Admin actors. Learners and Teachers use the Mobile app or Desktop app, while the Admin uses the Hub console. USB storage is an external destination for class-record export and Hub backup files. Optional remote access uses the same Hub services through a Cloudflare Tunnel; the tunnel does not act as an account or data-store actor.

![Figure 3.x: L.A.R.A. use case diagram](diagrams/use-case.png)

*Figure 3.x. Use case diagram showing the role-based interactions of Learners, Teachers and the Hub Admin with L.A.R.A.*

Solid connectors show actor participation. The «include» connector from account access to identity validation represents the required validation and session creation during registration or sign-in. The optional file attachment behavior «extends» announcement posting only when a Teacher adds a file. Class-code validation is included in a Learner's enrollment request; approval remains a later Teacher action and is not modelled as an included step. The Learner and Teacher share access to class materials, videos and classroom content; their permitted actions differ by role. Teachers review class performance through the gradebook, while Learners see only their own released grades and feedback. The contract supports class-record export for a Teacher or Admin, to a download or a mounted USB path. USB storage is also used by the Admin for backup and restoration.

The class-record export and Hub backup use cases are distinct: export creates a class spreadsheet, whereas backup creates a Hub archive. Starting an assessment and creating an attempt are separate contract operations; grading and score release follow submission and quiz settings. An active quiz attempt locks the tutor. These are required constraints and therefore do not use «extend». The figure includes only behavior supported by the current product requirements and API contract; it does not represent unsupported self-service PIN recovery, language selection, or local model inference.

| Use case | Actor(s) | Contract-grounded outcome |
|---|---|---|
| Register / sign in | Learner, Teacher | Learners register; Teachers and Learners sign in through Hub authentication. Admin setup is a separate Hub operation. |
| Request class enrollment | Learner | Submit a class code and wait for a class Teacher's approval. |
| View stream, modules and videos | Learner, Teacher | Read class announcements and learning materials; video media is streamed from the Hub or saved for offline access. |
| Manage classes and enrollment | Teacher | Create and manage a class, view the roster, approve or reject requests, and manage permitted classroom membership. |
| Manage classroom posts and comments | Learner, Teacher | Teachers create and moderate announcements; Learners and class Teachers exchange supported comments. |
| Manage materials, assignments and homework | Learner, Teacher | Teachers provide classwork and assignments; Learners submit work and view their own returned feedback. |
| Take or manage quizzes | Learner, Teacher | Learners complete one timed attempt; Teachers author, start, monitor and close quizzes. |
| Monitor grades | Learner, Teacher | Teachers view the class gradebook; Learners view only their own released quiz and homework results. |
| Request lesson guidance | Learner | Send a lesson-related question to the Hub service; requests are unavailable during an active quiz attempt. |
| Export class record | Teacher, Admin | Export a class record as XLSX or CSV to a download, or to a mounted USB target path. |
| Set up and administer Hub accounts | Admin | Establish the Hub Admin and create or reset accounts through the supported administration operations. |
| Back up or restore Hub data | Admin | Write a backup archive to the selected path or restore an archive after checksum verification. |
| Enable remote transport | Admin | Opt into the approved Hub tunnel configuration for Remote/Suspension Mode. This is a Hub operation, not a separate API account feature. |
