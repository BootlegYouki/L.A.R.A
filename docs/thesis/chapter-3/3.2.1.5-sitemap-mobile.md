# 3.2.1.5 Sitemap: Mobile App

The Mobile app provides separate navigation trees for the Learner and Teacher. Figure 3.x presents the designed classroom destinations and their relationships. Both roles use the same classroom services as the Desktop app, with a phone layout organized around a top app bar, a single column of cards and class navigation within thumb reach.

![Figure 3.x: Mobile app sitemap](diagrams/sitemap-mobile.png)

*Figure 3.x. Designed Learner and Teacher navigation trees for the Mobile app.*

**Learner navigation.** Hub connection provides nearby-Hub discovery and manual address entry. First-time Learners register and sign in; returning Learners use their existing accounts. Home provides enrolled and archived classes, Due soon, To-do and class-code entry. A request to join a class leads to a pending-approval view until the Teacher approves access. A previously authenticated Learner can reopen saved classroom content without reconnecting to the Hub.

Selecting a class opens its workspace. Stream provides announcements and permitted comments. Classwork organizes materials, assignments and quizzes under topics. Materials provide handout and video viewing, with Save for Home Study for downloaded resources. Assignment detail contains instructions, attachments, camera capture or an existing photo, submission status, private comments and returned feedback. My Work and quiz history display only the Learner's own released scores.

Quizzes provides available assessments, timed participation and submission status. An attempt started while connected can continue after disconnection, with answers and completion retained on the device until synchronization. The AI tutor provides lesson-grounded guidance outside an active attempt. Tutor controls and chat are removed while a quiz is being taken. Tutor access also depends on model availability; phones below 6 GB RAM use the Hub, while eligible phones may optionally use a local model.

**Teacher navigation.** Teachers sign in using accounts created by the Admin. Home provides teaching classes, class creation, work awaiting review and archived classes. The class workspace provides Stream, Classwork, People, Quizzes, Grades and class settings. Stream supports announcement authoring, attachments and comment moderation. Classwork supports topics, materials, assignments, homework review, points, feedback and private comments. People provides enrollment approval or decline and Learner removal while retaining historical scores.

Quizzes provides draft authoring and editing, start and close controls and participation monitoring. Grades provides a points-based gradebook and class-record export in XLSX or CSV format. The class record may be downloaded to the Teacher's device or written to USB storage through the Hub workflow. Owner-only class settings provide renaming, archiving and co-teacher management. Teachers have the same classroom functions on the phone as on the Desktop app, while dense tables are adapted to the phone layout.

**Shared navigation and disconnected operation.** Settings provides language selection, Hub connection information and session controls. The tree shows access to related functions rather than requiring every destination to appear in bottom navigation. Hub administration, Teacher-account creation, backup, restoration and remote-transport configuration remain outside the Mobile app. A saved remote Hub address provides an optional fallback after classroom-network discovery fails without introducing another role.

Locally stored classroom information supports loading, empty and disconnected states. Cached materials and downloaded videos remain available at home. Supported homework, private comments and completed quizzes are saved on the device until the Hub is reachable. Actions that require an available Hub display an explanation when disconnected. The sitemap describes the system design rather than the implementation status of individual screens.
