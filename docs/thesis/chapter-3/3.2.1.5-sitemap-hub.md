# 3.2.1.5 Sitemap: Hub Admin Console

The sitemap organizes the existing Hub window and the Admin functions specified by the PRD. It is a top-down tree of screens and functional destinations, rather than a list of invented browser routes. The only implemented screen in the examined `server/ui/src/` code is the Hub address and status view, which includes a language toggle, loading state, missing-network message, and startup-failure message.

![Figure 3.x: Sitemap of existing and planned Hub Admin console functions.](diagrams/sitemap-hub.png)

*Figure 3.x. Sitemap of existing and planned Hub Admin console functions. Solid borders identify the existing window and view. Dashed borders and the word “Planned” identify functions specified but not built in the examined UI. Editable source: [sitemap-hub.drawio](diagrams/sitemap-hub.drawio). The PNG is exported with an opaque white background.*

The existing view displays the classroom-network address and Hub running state through the `lan_address` Tauri command. Its English and Filipino dictionaries support the language toggle on the same screen; the toggle is not represented as a separate settings screen. Port-health logic and installer firewall checks exist in Hub modules, but the dedicated port-health screen is planned and therefore retains a dashed border. The presence of that logic does not establish that a dashboard screen has been implemented.

The planned first-run PIN setup creates the single Admin account on the Hub PC. Planned PIN sign-in protects the Admin console's account, export, and backup functions. Its functional destinations comprise teacher-account management and PIN reset, port health, AI status, USB gradebook export, backup and restore, and the opt-in Remote/Suspension Mode toggle. Gradebook export uses the specified `.xlsx` or `.csv` formats; backup and restore use the defined archive operations. AI status concerns the optional local model runtime, including unavailability, without suggesting that another Hub function requires AI. Remote/Suspension Mode is an administrative transport option and does not introduce a separate remote account or classroom screen. The tree groups these specified functions for manuscript presentation; it does not claim that their final page arrangement or navigation has been approved or built.
