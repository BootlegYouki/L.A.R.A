# 3.2.1.2 Context Diagram

The context diagram defines the boundary of the proposed L.A.R.A Hub and its exchange of information with the Learner, Teacher, Admin, and USB Drive. The Mobile app and Desktop app provide access to the Hub through the classroom network.

![Figure 3.x: Context diagram of the proposed L.A.R.A Hub.](diagrams/context-diagram.png)

*Figure 3.x. Context diagram of the proposed L.A.R.A Hub.*

The Learner provides registration details, class-code join requests, comments, homework submissions, quiz answers, and questions for the Socratic tutor. The Hub returns enrollment decisions, learning materials, classwork, quizzes, score receipts, and grounded guidance. The Teacher provides classroom information, enrollment decisions, announcements, materials, assignments, quiz settings, and homework grades. The Hub supplies class records, submissions, quiz progress, results, and gradebook files. A gradebook file can be downloaded to the Teacher's device or written to the USB Drive. The Admin manages the Hub PIN, teacher accounts, PIN resets, exports, backups, and restoration. The USB Drive receives gradebook files and backup archives and supplies an archive when restoration is requested. The AI model operates within the Hub. Remote/Suspension Mode uses an opt-in Cloudflare Tunnel to carry the same classroom exchanges; it changes the transport without adding another actor or data repository.
