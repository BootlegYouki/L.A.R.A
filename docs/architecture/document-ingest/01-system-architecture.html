System architecture: the Hub serves files, the devices parse and tutor

Hub, devices, discovery and remote mode on one page. The Hub only stores and serves files and runs the classroom, quizzes, sync and export. Each device parses allowed handouts on the first AI tap and runs the tutor on a small model. Boxes say built, partly built, planned or new.
