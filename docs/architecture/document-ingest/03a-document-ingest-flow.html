Document ingest: the Hub serves the file, each device parses it

A handout is uploaded like any other. The Hub only stores and serves the file. Mobile and desktop download it, extract the text, clean it and cut it into chunks per one shared spec, and keep them in local SQLite for the on-device tutor.

Sources: backend/src/routes/materials.rs, routes/files.rs, contracts/schema/client_offline.sql, rules/database-and-sync.md §3, PR #337, PR #349, Lead decision of 2026-11-20. The Hub parser described in server/docs/document_chunking.md goes away.
